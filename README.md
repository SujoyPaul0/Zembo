# Zembo – 2D RPG Game  

## Overview  
*Zembo* is a **2D Role-Playing Game (RPG)** built with **Pygame**. Players control a character equipped with weapons (**sword, spear**) and magical abilities (**air bending, water bending**) while navigating a 2D world, battling AI zombies, and facing two unique boss enemies.  

## Features  
- **Character Movement**: Explore a 2D map with fluid movement.  
- **Combat System**: Switch between weapons and magical abilities.  
- **AI Enemies**: Zombies with attack behavior.  
- **Boss Battles**: Two powerful boss enemies with unique mechanics.  
- **Dynamic UI**: Visual effects, health bars, and attack animations.  
- **Background Audio**: Engaging sound effects and music.  

## Technologies Used  
- **Programming Language**: Python  
- **Framework**: Pygame  
- **Version Control**: Git  

## Development Timeline  
- **Month 1**: Core mechanics (movement, combat, AI behavior).  
- **Month 2**: Magic system, weapon switching, level design.  
- **Month 3**: Polishing, playtesting, and debugging.  

## Folder Structure  
```
/Zembo
│── /audio        # Background music and sound effects  
│── /graphics     # Sprites, animations, visual assets  
│── /maps         # Level designs  
│── /code         # Game logic and supporting modules  
│── main.py       # Manages the game loop  
│── settings.py   # Configuration settings  
│── enemy.py      # AI enemy behavior  
│── entity.py     # Base class for game entities  
│── level.py      # Level management  
│── magic.py      # Magic system implementation  
│── debug.py      # Debugging and performance monitoring  
```
